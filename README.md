# Project Aether

An ESP32-based flight control system for a fixed-wing RC aircraft.

## Goals

- IMU-based attitude estimation
- Flight stabilization
- PID control
- RC input processing
- Servo/motor control
- SD-card black-box flight logging
- Post-flight data analysis

## Hardware

- ESP32
- MPU6050
- RC receiver
- Servos
- BLDC motor + ESC
- MicroSD card module
