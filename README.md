# Project Aether

An ESP32-based flight control system for a fixed-wing RC aircraft.

## Goals

- IMU-based attitude estimation
- Flight stabilization
- PID control
- RC input processing
- Servo/motor control
- SD-card black-box flight logging
- Post-flight data analysis

## Hardware

- ESP32
- MPU6050
- HMC5883
- FS IA6B RX + FS i6 TX
- Servos
- BLDC motor + ESC
- MicroSD card module

## Status

In development of v1
